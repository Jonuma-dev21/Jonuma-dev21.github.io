# Portfolio — Jonas Numa

Site statique compatible GitHub Pages, sans dépendance externe.

Copier index.html, style.css, script.js et projects/README.MD dans le dépôt existant. Conserver le dossier assets et placer le CV à l’emplacement assets/documents/CV_Jonas_Numa.pdf. Les liens vers les dépôts individuels ne sont pas renseignés : ajouter uniquement ceux qui existent et sont publiables.

Tester localement : `python3 -m http.server 8000`, puis ouvrir http://localhost:8000.

Les exercices de sécurité sont présentés dans leur contexte pédagogique et autorisé. Ne pas publier de secrets, de données privées ou de solutions de laboratoires non autorisées.
